Host Free on GitHub Pages

Publish this interactive 3D Cell website directly from your browser in 4 simple steps:

  1. 1
    Create GitHub Repository Go to github.com/new, name it (e.g. cell-3d-explorer), and click Create repository.
  2. 2
    Upload index.html In your repository, click Add file → Create new file. Name the file exactly index.html.
  3. 3
    Paste Code & Commit Paste this code inside index.html and click Commit changes.
  4. 4
    Enable Pages Website Go to repository Settings → Pages tab. Under Build and deployment, set Source to Deploy from a branch, select branch main, and click Save.
Your live link will be ready in 1 minute at https://<your-username>.github.io/cell-3d-explorer!
